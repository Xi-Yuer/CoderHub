# 打造一个程序员社区

## 社区介绍

- 面试宝典
- 编程社区
- 技术问答、分享、讨论
- 技术新闻
- 求职简历
- 技术书籍、视频推荐
- 开源项目

## 目标价值

- 提供一个编程技术社区，让程序员能够在这里交流技术，分享经验，解决问题。
